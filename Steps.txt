1 - first we need a sockerfile with 

FROM php:7.2-apache
COPY index.php /var/www/html/

- to create an image 

docker build -t my-php-app .

- view images

docker images

- run the image

docker run -p 8080:80 --rm my-php-app

- stop the container 

docker ps
docker stop {containerID}
