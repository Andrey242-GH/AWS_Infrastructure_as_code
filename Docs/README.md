# Documentation Structure

This folder is organized by topic so the learning path is easier to follow.

## 01-setup
- [01-install-terraform-and-aws-cli.md](01-setup/01-install-terraform-and-aws-cli.md) — install Terraform and AWS CLI
- [02-aws-credentials-in-codespaces.md](01-setup/02-aws-credentials-in-codespaces.md) — configure AWS auth in GitHub Codespaces
- [03-github-codespaces-setup.md](01-setup/03-github-codespaces-setup.md) — environment setup notes

## 02-aws-fundamentals
- [01-networking-concepts-explained.md](02-aws-fundamentals/01-networking-concepts-explained.md) — VPCs, subnets, routing, and AWS networking basics

## 03-infrastructure-as-code
- [01-terraform-workflow.md](03-infrastructure-as-code/01-terraform-workflow.md) — create, inspect, change, and destroy AWS resources with Terraform and AWS CLI

- [02-docker-setup-and-usage.md](04-containers/02-docker-setup-and-usage.md) — Docker setup and course Lesson 1: run PHP with Apache, then inspect images and active containers

## 05-github
- [01-github-repository-setup.md](05-github/01-github-repository-setup.md) — repo setup and GitHub workflow

## Suggested learning order
1. Setup your environment
2. Learn AWS networking concepts
3. Practice infrastructure provisioning with Terraform and AWS CLI
4. Study the Docker lessons, starting with running Apache and inspecting images and containers
5. Manage GitHub repo workflow
